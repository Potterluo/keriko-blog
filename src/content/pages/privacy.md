## 概述

欢迎访问 **kerikoの行星观察笔记**（以下简称“本站”）。本站由 **Keriko** 运营。

本政策说明本站在你访问和使用本站时可能处理的信息、处理目的、相关第三方服务，以及你可以如何联系我们。本站仅在提供功能、保障安全和维护服务所需的范围内处理信息。

## 主题默认行为

Misthaven 本身是一个静态博客主题，默认不提供用户账户、广告或访问统计。本站的评论功能通过 Giscus 接入 GitHub Discussions 提供，具体见下方「评论」小节。

### 本地存储

本站使用浏览器 LocalStorage 保存明暗模式偏好，存储键为 `misthaven-theme`。该偏好通常仅保存在你的浏览器中，不会由主题主动上传到服务器。你可以通过浏览器设置清除它；清除后，站点会重新使用系统主题偏好。

### 默认外部资源

主题的初始配置包含以下外部资源。站点运营者应根据最终配置保留、修改或删除本节：

| 服务         | 默认用途             | 可能发生的处理                                                                                                                                                                                                                  |
| :----------- | :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Gravatar** | 提供站点头像源文件。 | 在默认静态构建流程中，Astro 会在构建期间获取并优化远程头像，通常由本站提供构建后的本地资源。若你改变图片处理或部署方式，请重新确认访问者是否会直接请求 Gravatar。请参阅 [Automattic 隐私政策](https://automattic.com/privacy)。 |

### 评论

本站使用 [Giscus](https://giscus.app) 提供文章评论，评论数据基于 GitHub Discussions 存储。发表评论需要登录 GitHub 账号。过程中可能处理的信息包括：

- **GitHub 用户名与头像**：用于展示评论者身份；
- **评论内容**：公开发布在本站对应文章页与 GitHub 仓库（[Potterluo/keriko-blog](https://github.com/Potterluo/keriko-blog)）的 Discussions 中；
- **页面地址与标题**：用于将评论关联到对应文章。

评论内容由 GitHub 保存与管理，遵循 [GitHub 隐私声明](https://docs.github.com/privacy) 与 [GitHub 条款](https://docs.github.com/terms)。如需更正或删除评论，可在文章页通过 GitHub 操作，或通过本页末尾的联系方式联系我们。
