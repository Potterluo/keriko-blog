整期节目里他反复回到同一个问句：这个零件的输入是什么，输出是什么，向量多长。问完就没什么可讲的了，剩下的部分交给一个神经网络去拟合。他在分 P 里说过一句很直白的话，大意是 AI 领域很多人听不懂，核心原因是没人把问题的定义讲清楚。

## 一、定义问题：一个函数，三个数字

大模型的起点朴素得有点过分：找到一个函数，输入是若干个词，输出是下一个词。

这种函数当然不能手写，所以用它最通用的形式去逼近，也就是一个带未知参数的神经网络，再拿海量已知的输入输出把参数解出来。训练数据在左边，参数在右边，大模型和这个描述的区别只是两边的量级。

他给 GPT-2 举了三个数字，用来把这个函数「丈量」出来：

| 位置       | 数字  | 含义                  |
| :--------- | :---- | :-------------------- |
| FFN 输入   | 768   | 一个 token 的向量长度 |
| FFN 隐藏层 | 3072  | 中间升维到多少        |
| 输出层     | 50257 | 词表大小，即分类数    |

看到这三个数字，架构的大半就已经定了。输入是 768 维，输出是 50257 路分类，中间的神经网络负责把它们连起来。他自称代入的角色是「架构师」，架构师不纠结内部实现，只定义接口。

![图 1 把大模型看成一个函数：入口是 768 维的词向量，出口是 50257 路打分，中间那层神经网络负责连接两端](/img/029-from-definition-to-agent/fig-01.svg)

## 二、词向量：一个数字不够用

文字要先变数字，这是所有实现的第一步。问题在于用几个数字表示一个词。

他先讲了个小实验：给一群人编号，若用一个数字表示，性别混在一起就不可分；换成两个数字，只要看第一个数字是 0 还是 1 就能分开。一维数轴上做不到的事，二维平面上一条直线就够了。

所以词也得用一组数字表示。这套表示要满足一个性质：意思相近的词，向量方向也接近。用数学语言说，两个向量的点积或余弦相似度要大。

人工定义每一维的含义是死路，词的语义太丰富。剩下的极端方案是 one-hot：维度等于词表大小，只有一个位置是 1。这条路有两个硬伤，向量维度跟着词表一起爆炸（50257 维），而且任意两个词的相似度都是 0，度量不了远近。

Word2Vec 的做法是把「含义」交给训练：随机初始化一个大矩阵，纵向是词表，横向是向量维度，然后拿语料做正负样本训练，让中心词和上下文词的点积变大，和随机采样的负样本点积变小。训练完这个矩阵就带着语义了，降维看一眼，`king - man + woman ≈ queen` 这类关系会自己冒出来。

但它有两个问题。每个词的向量是静态的，同一个「苹果」在水果和手机两种句子里长得一样；而且这个矩阵通常被当成下游任务的固定输入，不参与端到端训练。

后来 BERT 和 GPT 干脆把这条路推平了：嵌入矩阵就是随机初始化一个矩阵，跟着整个模型一起训。他在视频里说，演进这么多年，最终的嵌入模型变成了最简单的模样，一个随机矩阵而已。GPT-2 里这个矩阵的横向长度就是 768。

代码也就两行的事：

```python
vocab_size = 50257
embedding_dim = 768
embedding = nn.Embedding(vocab_size, embedding_dim)
```

## 三、FFN 与投影：真正在干活的两层

文字变成向量之后，进入那个「通用函数」。这一段他讲得最用力，因为很多初学者卡在这儿。

神经网络被拆成两段。第一段是 FFN，768 升到 3072 再降回 768，两头维度一样，所以可以堆很多层。第二段是线性投影，768 直接打到 50257，输出每一个词的可能性。投影层没有激活函数，纯线性，几何上就是把一个点映射到另一个空间。

他在这一节的结论是：整期节目里最容易被忽略、但真正解决问题的是这个神经网络，注意力只是一个外挂。原话的意思是，注意力机制说穿了无非是给神经网络的输入做点手脚，让输入里带上上下文信息，仅此而已。

这个说法有点绝对，但它解释了为什么那么多人学了 QKV 还是不懂 Transformer：QKV 只是配料，主菜是那个被默认跳过的前馈网络。

## 四、注意力：一次加权求和，外面包了几层

单个词的神经网络有个致命缺陷。它只看当前这个词的向量，可下一个词是什么，取决于前面所有词。神经网络再强，也得先拿到信息。

补救办法是最朴素的那种：把前面所有词的向量加进来。加完发现不同词的重要性显然不一样，于是把求和升级成加权求和。这一步就是注意力的全部内核。

接着是把权重算出来。权重表示上下文词和当前词的相关性，两个向量的相关性可以用点积衡量，那就用点积当系数。

但直接拿词向量自己做点积，灵活度不够。于是每个词的向量分裂出两路新向量：一路用来「发问」，一路用来「被查询」，也就是 Q 和 K。用当前词的 Q 和所有词的 K 做点积得到系数，再拿这些系数去加权第三路向量 V。

Q、K、V 从哪来？三个可训练矩阵，乘一下就有了。乘矩阵本质上是一个没有激活函数的单层神经网络，输入输出维度相同，参数随机初始化，跟着模型一起训。

最后是灵活度的最后一次升级：每个词不只分裂出一组 QKV，而是分裂出多组，每组各自做注意力再把结果拼起来。这一组叫一个头，整个结构叫多头注意力。

![图 2 注意力的四层包装：从直接相加，到加权求和，到 QKV 三路，再到多头拼接；每一层都在给同一个思路加灵活度](/img/029-from-definition-to-agent/fig-02.svg)

值得记的是他给这串演进的评价：每一层都在解决「不够灵活」，一层一层加上去的包装，让一个「加权求和」看起来像一门学问。

## 五、拼装：一张表看完整个 block

把零件摆齐，剩下的就是接口对齐。

| 步骤       | 输入 → 输出      | 说明                               |
| :--------- | :--------------- | :--------------------------------- |
| 分词       | 文本 → token ID  | 最小单位从字改成词，叫 token       |
| 词嵌入     | ID → 768 维      | 从嵌入矩阵按行取                   |
| 位置编码   | 768 → 768        | 加一个同样长度的向量，补上位置信息 |
| 多头注意力 | 768 → 768        | 混入上下文，维度不变               |
| Add & Norm | 768 → 768        | 残差相加，再归一化到均值 0 方差 1  |
| FFN        | 768 → 3072 → 768 | 升维再降维，维度仍不变             |
| 线性投影   | 768 → 50257      | 打到词表上，得到 logits            |
| Softmax    | 50257 → 概率     | 压到 0 到 1，总和为 1              |

注意力层和 FFN 层的输入输出维度都不变，所以能首尾相接堆 N 层，这一整块叫 Transformer block。

两个细节值得单独说。位置编码在原始论文里是用正余弦函数算出的固定值，后来的模型换成了可训练的嵌入，再后来是旋转位置编码。残差连接是「把输入原封不动加到输出上」，作用是让训练更稳。归一化则是把向量压回稳定范围，代价是丢掉一部分绝对幅度，保留相对差异。

还有一个容易被忽略的历史细节：原始论文是 encoder 加 decoder 的两段结构，现代大语言模型基本只用 decoder 那一段。你在论文里看到的左图，和现在跑的模型，不是一张图。

## 六、训练：从接龙到会思考

有了架构，训练反而简单。取一段文本，前面当输入，后面当答案，算误差、反向传播、更新参数。因为答案是从原文里抠出来的，不需要人工标注，这种玩法叫自监督学习，这个阶段叫预训练。GPT 的全称就是生成式预训练 Transformer。

预训练出来的模型会做文字接龙。有意思的是，只要参数和数据给够，接龙能接出些别的东西：给几个例句，它能照着翻译；换个任务描述，它能照猫画虎。这种从上下文示例里学新任务的能力叫少样本学习，也是「一个通用模型取代一堆专用模型」的由来。

但通才不等于好用。纯预训练的模型面对问题时，很可能继续跟你接龙。于是有了后训练，用人工精心标注的问答数据做监督微调，把通才变成专才。他自己打了个比方：人在自然环境里长大，接触海量粗糙信息，之后再去做专项训练。

再往后是把智能榨出来。思维链就是其中最简单的一招：大模型没有心算过程，所有推理必须「说出来」，所以在提示词里加一句「请一步一步思考」，效果上就像变聪明了，参数量没变，架构没变。更重的手段是强化学习，按反馈来源分成基于人类反馈和基于可验证奖励两类。

## 七、从模型到 Agent：一路造出来的那些词

这一段是整期视频里最开心的部分。他让观众扮演老板，把大模型当员工小 L，然后一步步逼出今天所有的概念。

小 L 只会一问一答，说完就结束，不能追问。为了压榨它，你先给每次对话起名叫 prompt，再把背景信息和最终指示分开，背景那部分叫 context。想追问又不能追问，那就把此前所有对话塞进 context，伪装成多人聊天，这些特殊上下文叫 memory。

小 L 不会上网，你就替它查，查完再喂给它。为了不显得自己像牛马，你写个程序代替你跟小 L 沟通并完成搜索，外人看来仍然是一问一答，只是对象变成了那个程序。这个程序叫 agent。

既然能搜网页，那也能搜本地文档和数据库，只不过要用向量检索，把语义相近的片段找出来塞进上下文，这叫 RAG。

接着是格式问题。agent 和大模型之间如果一直用自然语言沟通，程序没法解析，于是约定一套固定格式，规定工具怎么调、参数怎么填，这叫 function calling。工具如果不想写死在 agent 里，可以单独做成服务，那就还需要一套发现和调用的规范，比如「列工具」和「调工具」两个接口，这叫 MCP。

再往后是流程。有些步骤很稳定，每次都让 agent 自由发挥既不稳定又费 token，于是把固定步骤写成脚本，中间需要判断的地方才交给大模型，这套东西叫 workflow。为了照顾非程序员，又有了拖拽式的低代码版本。可文件格式一多，分支就爆炸，于是改成：把所有脚本放一个目录，写一份说明文件，让 agent 读完再按需挑选。最后干脆把「先读说明」这句话固化成一个约定位置的文件，这就是 skill。

任务再复杂，主 agent 的上下文会撑爆，于是允许把独立子任务丢给子 agent 完成，子 agent 的上下文不回传主流程，这叫 subagent。

他自己也承认，这些词里相当一部分只是把提示词换了个地方存。

## 八、架构的忒修斯之船

最后一节他换了个视角：不看应用层那些新词，看模型本身的零件还剩几个原装的。

他把原始 Transformer 拆成五块，然后逐块盘点这些年被换掉的部分。

位置编码：正弦固定值被旋转位置编码淘汰，后来又出现支持更长上下文的扩展，甚至有人证明不用位置编码也能成立。

归一化：LayerNorm 变成 RMSNorm，位置可以放在注意力之前、之后、前后都有，甚至作用到 Q、K、V 上，排列组合基本被穷举。

残差连接：多年来没人敢动，最近两年才有人尝试改造，还在探索阶段。

FFN：拆成多个小专家，加一个可训练的路由层，每个 token 只走其中一个，总参数不变但推理只激活一部分，这就是 MoE。现在的模型名里经常带 `A3B` 这种写法，后面的数字是每次激活的参数量，前面的 30B 是总参数。

注意力：MHA 之后有 MQA、GQA、MLA，有走稀疏路线的，也有把复杂度压成线性的，还有 Mamba 这类完全换掉注意力模块的，以及把两者混着用的混合注意力。

![图 4 五个零件的替换情况：位置编码、归一化、残差、FFN、注意力都被换过一轮，只有残差还留着改造空间](/img/029-from-definition-to-agent/fig-04.svg)

盘点完的结论有点扫兴：能改的地方基本被挖干净了，模型之间的差距在缩小。他补了三个解释。Scaling law 遇到瓶颈，互联网数据被挖得差不多了，算力和规模短期也上不去。Bitter lesson 说人类在架构上精心设计的小聪明，在更大规模面前反而可能是阻碍。Moravec 悖论说，对人类难的事对机器简单，反之亦然，底层架构未必是唯一正确的答案。

## 收尾

这期视频真正的贡献不在任何一个公式，而在于把「定义输入输出」当成理解新东西的统一入口。

拿它当检查表很实用：下次看到一个新架构、一个新缩写，先问输入是什么、输出是什么、向量多长，问完大半就清楚了，剩下的通常是一个更简单的旧想法的包装。

至于那些名词，作者自己也说了，不应该高估单个技术的贡献，也不应该低估量变到质变的过程。
